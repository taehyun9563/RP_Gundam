# 《기동전사 건담: CHAOS》 제9권 — PLAN B TRIAL·조직 TRIAL·ZERO·카오스 최초 배치형
> 2026-10-26 사용자 승인. C.E. 73, RP 미개시. 본 문서는 설정 정본이며 RP 사건 기록이 아니다.
> 기존 제1·5·6·7·8권, 장기전개 구상 및 AI 통합지침의 '에테르니아=전쟁 확산·혼돈 자체 추구' 조항과 카오스의 구형 날개·무장 구성은 본 승인 범위에서 대체한다. 기존 다른 인물·기체·기술·역사는 유지한다.

## 1. 이오리아의 이중 계획
- **PLAN A / 솔레스탈 비잉:** 무력 개입으로 전쟁을 억제하고 인류의 상호 이해·통합·혁신을 촉진하여 다가올 대화에 대비한다.
- **PLAN B — TRIAL(트라이얼):** PLAN A가 촉진한 인류의 혁신과 다가올 대화 준비 상태를 독립적으로 검증한다. 내추럴·코디네이터 간 상호 이해, 국가 간 협력, 이노베이터 수용, 위기 대응, 미지 지성과의 소통 가능성을 평가한다. 전투 승패만으로 합격·불합격을 자동 판정하지 않는다.
- 두 계획은 원래 동등하고 독립된 역할이다. PLAN B가 PLAN A의 인원·베다 A구획·건담을 자동 통제할 권한은 없다.
- PLAN B — TRIAL은 베다 연동 GN 건담의 제어 기능인 **트라이얼 시스템(Trial System)**과 별개의 개념이다.

## 2. 이현의 독자적 결단과 조직 노선
- C.E. 71 SEED 전쟁에서 솔레스탈 비잉이 무력 개입했고 전쟁은 무승부·협정 종전되었다. C.E. 73 지구연방과 플랜트·자프트 사이에 전쟁이 재발했다. 에테르니아는 C.E. 71에 참전하지 않았다.
- **이현은 재개전을 근거로 솔레스탈 비잉의 PLAN A가 실패했다고 판단한다.** 이는 이현의 입장이며 이오리아나 세계관이 PLAN A의 객관적 실패를 판정한 것은 아니다.
- 이현의 승인된 조직 노선: **PLAN B의 검증을 지속하면서 PLAN A의 실행까지 직접 담당한다. 솔레스탈 비잉의 무력 개입을 저지한다.**
- 이는 이오리아의 새 지시나 베다의 승인, 솔레스탈 비잉의 동의가 아니라 이현의 독자적 판단이다. PLAN A 실행 선언과 실제 지휘·통제권 확보는 구분한다.
- 조직은 단순 관찰자가 아니라 전술예보사의 독자적 작전으로 전쟁에 개입한다. 솔레스탈 비잉과는 실행권·전술·작전목표가 충돌하여 교전할 수 있으나 모든 접촉이 자동 교전·전멸로 이어지지는 않는다.
- **전쟁 확산·학살·민간인 희생·국가 붕괴 자체를 조직의 목표로 삼는 구 설정은 폐기한다.** 피해는 전쟁의 실제 결과로 발생할 수 있으며 무조건적인 성공이나 실패가 아니다.
- 문명 리셋·인류 소멸은 초기 확정 목표가 아니다. 추후 근본 노선 변경은 이현 사용자 전속이다.

## 3. 명칭과 코드네임 — 확정
- **조직의 코드네임: TRIAL(트라이얼)** — 정식 채택. 기존 비밀 무장조직의 실명 **에테르니아(ETERNIA)**는 보존하고, 외부 작전·교신·식별에는 TRIAL을 사용한다. 이는 조직 전체의 역사·인원·시설을 새로 창설하거나 이전한다는 뜻이 아니다.
- **이현의 작전·파일럿 코드네임: ZERO(제로)** — 정식 채택. 본명 이현은 유지한다. ZERO는 이현의 다른 인격이나 새로운 인물이 아니다.
- **전용기 명칭: CHAOS(카오스)** — 그대로 유지. '카오스 오메가'는 채택하지 않는다.
- 명칭 혼동 방지: '조직 TRIAL'은 무장조직의 작전명, 'PLAN B — TRIAL'은 검증 계획, '트라이얼 시스템'은 GN 기체 제어 기술이다.
- 다른 11명의 마이스터와 전용기, 에리시아·레이먼드·노아 및 아르카디아의 직무는 기존 정본대로 유지한다.

## 4. ETN-G00 CHAOS — C.E. 73 최초 등장형
- **기존 카오스 구형 설계는 폐기.** 개조형·후속기·개조 완료 이벤트·'카오스 오메가'는 없다. 아래 형상이 처음부터 설계·완성된 **RP 시작 시점의 최초 배치 카오스**다.
- 색상·인상: 무광 흑색 장갑, 진홍색 발광선과 강조부, 흑철색 관절, '전쟁의 사신' 같은 실루엣.
- 동력: 기존 배정 오리지널 GN 드라이브 **2기**, 트윈 드라이브. 새 드라이브 추가 없음.
- 기존 공통 기능: 트란잠, 조건부 양자화, 제한적 나노프레임, 베다 보조와 트라이얼 차단 시 이노베이터 독립 제어.
- **전 날개를 대형 GN 엑스칼리버 블레이드 윙으로 구성.** 날개 각각은 실체 검날이며 복수의 GN 소드 판넬을 내장·결합한다. 평상시 날개처럼 수납·전개하고 전투 시 날개검과 판넬을 분리해 독립 제어할 수 있다.
- **이렐리아형 검무 제어:** 진정한 이노베이터의 뇌양자파와 전용 제어계로 다수 검날의 위치·궤도·각도·공격 순서를 입체적으로 조정한다. 근접 검술, 다방향 참격, 포위, 차단, 방어와 중거리 압박을 연동한다. 이렐리아의 연출을 전투 모티프로 삼되 다른 작품의 초능력을 그대로 이식하지 않는다.
- **결전검:** 각 블레이드 윙이 자체 소드 판넬을 결합해 초고밀도 GN 빔을 **원거리로 직접 발사하는 포격 기능**. 단순 빔 사벨·근접 참격·검에서 뻗는 칼날로 판정하지 않는다. 여러 윙이 각각 다른 목표를 공격하거나 동일 목표에 집중할 수 있으나 GN 입자 공급·제어·발사각·재충전 제약을 따른다.
- 날개검이 분리·손상되면 해당 위치의 자세제어·방어·화력에 제약이 생긴다. 판넬은 동시에 결합 상태와 분리 상태일 수 없다. 다중 제어·포격·고기동·GN 필드는 공통 입자 예산을 공유한다.
- **고성능 원·중·근거리 만능형, 근접전 약간 우세. 전문 저격 기능 없음.** 중·원거리 실전 화력은 강력하지만 전문 저격형 아스트라이아의 역할을 대체하지 않는다.
- **별도 궁극기·필살기 체계 없음.** 결전검은 통상 무장 운용 모드이며 트란잠·양자화는 기존 기술의 조건부 운용이다.
- 날개검 정확한 개수, 각 날개당 판넬 수, 기존 별도 발검식 주검·라이플·캐논의 존치 여부, 전고·중량은 **미확정**. 앞선 구형 제원의 '소드 판넬 8기', '별도 엑스칼리버 1기', '라이플·캐논 기본 장착'을 신형 확정값으로 자동 계승하지 않는다.

## 5. 지휘·전투·보안의 보존
- 이현(ZERO)의 직접 행동·대사·내심·출격·무장 선택·전술 결정은 사용자 전속. 다른 마이스터 11명은 독립 판단한다.
- 전술예보사 에리시아는 TRIAL의 새 노선 아래 임무·편성·작전·철수 판단을 자율 수행한다. 레이먼드는 아르카디아 함장, 노아는 정비책임자다. 매번 이현의 결재를 요구하지 않는다.
- VEDA는 단일 시스템이며 A/B 보안구획·레벨 7의 제한·트라이얼 시스템의 순간 간섭과 독립 제어 전환은 그대로 유지한다.
- 오리지널 GN 드라이브 총 **28기**(솔레스탈 비잉 4기, TRIAL/에테르니아 24기)를 보존한다. 기존 정본의 '더블오 2기 + 켈딤·아리오스·세라비 각 1기' 동시 운용과 CB 보유 4기 간 부족분 1기 문제는 **미해결**이며 임의 증설하지 않는다.
- C.E. 73 RP 미개시. 최초 공개 출격, 전과, 손상, 개량·개발 사건은 아직 발생하지 않았다. 전투 결과·원작 인물의 사망·기술 발전은 실제 RP에서 판정한다.

## 6. 충돌 처리
이 승인된 제9권은 **PLAN B 목적, 조직/파일럿 코드네임, ETN-G00 카오스 최초 등장 설계**에 한하여 기존 권의 상충하는 조항보다 우선한다. 나머지 제1~8권의 역사·인물·기체 11기·베다·기술·운영규칙은 계속 유효하다. 이후 관련 권의 충돌 문구를 정리할 때 본문 외 제원을 임의 변경하지 않는다.
